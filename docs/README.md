## Que es este proyecto

Este repositorio es un starter pequeno sobre Remix 3 orientado a una arquitectura basada en agentes y en ownership claro de rutas. No intenta darte una aplicacion gigante de inicio; te da una base minima, tipada y facil de extender.

Hoy incluye:

- un servidor HTTP en Node
- rutas tipadas
- dos pantallas server-rendered (`/` y `/auth`)
- un pipeline de assets para modulos del navegador
- una capa de UI compartida para layout y renderizado
