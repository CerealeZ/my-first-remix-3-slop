## Como leer estos ejemplos

- Estan escritos para este starter, no para una SPA de React tradicional.
- Priorizan el flujo server-first.
- Cuando aparece codigo de cliente, esta puesto como capa adicional, no como punto de partida.

## Regla comun a todos

Primero consigue una ruta correcta en el servidor. Despues agrega interactividad, estado local o streaming si el caso lo pide.
